# Get-HclEdit

## SYNOPSIS
Returns the binary location and version for hcledit

## SYNTAX

```
Get-HclEdit [<CommonParameters>]
```

## DESCRIPTION
Returns the binary location and version for hcledit

## EXAMPLES

### EXAMPLE 1
```
Get-HclEdit
```

Binary                                                                              Version
------                                                                              -------
C:\Users\pwshhcl\modules\PwshHcl\0.0.1\bin\hcledit_0.2.19_windows_amd64\hcledit.exe 0.2.19
